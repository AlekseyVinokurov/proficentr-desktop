Реализованы девять категорий, поиск/фильтры, карточка, импорт PDF и дополнительного DOCX, встроенный просмотр и печать PDF, проверенные копии, неизменяемые редакции, история статусов и необязательные связи с конкретными редакциями приказов и протоколов. Миграция № 17 сохраняет прежние данные. Файлы находятся отдельно в `organization/regulatory`, контролируются SHA-256, переносятся и резервируются вместе со всем хранилищем. Полноценные роли остаются для P06: подготовлены проверки `regulatory.read` / `regulatory.write`, по умолчанию изменения доступны локальному пользователю. Удостоверенная личность автора изменений пока не фиксируется. Подробности и ограничения — в [руководстве N02](regulatory-documents.md). Локально пройдены 62 адресные проверки N02 и связанных компонентов: импорт, редакции, статусы, ссылки, повреждение, отказы доступа, ошибки записи/SQL/commit, перенос и миграция, интерфейс, копии и печать в PDF; также Security Policy, Bandit и проверка diff. Полный набор тестов, Windows-сборка и проверки зависимостей выполняются существующим Windows CI по push; результат текущего запуска указывается в отчёте задачи. Release не публикуется.

## T06 — библиотека рабочих шаблонов

Интегрированы 24 предоставленные формы T01–T05 из пяти ZIP; содержание и оформление сохранены, переменные сопоставлены с закрытой схемой существующего DOCX-движка. Скорректирована подготовка тестовых баз прежних версий: из снимков исключаются более новые таблицы, последовательность миграций проверяется без ослабления.
