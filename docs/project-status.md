# Состояние проекта

P01, P01.1, P02.1, P02.2 приняты; исходный коммит 6378427.

U01 + S01: реализованы проверка официальных релизов, Ed25519, внешний Windows updater, резервирование/пробные миграции, интерфейс «О программе», политика приватности, SECURITY.md и защищённый workflow выпуска. Основной сценарий собранного приложения проверяется Windows CI; локально Windows EXE не собирается. На завершение U01/S01 локально и в Windows CI прошли 146 тестов (включая 98 исходных). [Windows CI с проверкой собранного приложения](https://github.com/AlekseyVinokurov/proficentr-desktop/actions/runs/44541542865) успешен: подпись тестового пакета, безопасная распаковка, отдельный helper, переключение onedir, подтверждённый запуск нового EXE, сохранность базы/вложения/настроек и отказ несовместимой схемы. U01/S01 реализован и проверен в этих пределах; проверка публичного канала между опубликованными релизами остаётся отдельным шагом после их выпуска.

До первого стабильного выпуска: утвердить лицензию и настройки защиты main/релизных тегов. Сам стабильный релиз не опубликован; публичный канал обновления между двумя официальными версиями ещё нельзя проверить. Authenticode, роли, шифрование базы и журнал аудита не реализованы. Порядок восстановления — в [updates.md](updates.md); устройство хранилища, ограничения модулей и инструкции разработчика — в [development.md](development.md).


D01: README переработан для потенциального пользователя; технические инструкции и ранее принятые решения перенесены в development.md. Программный код, интерфейс, миграции и механизмы обновления не изменялись. Лицензия не выбиралась, стабильный релиз не публиковался.

P02.3: реализован отдельный реестр организаций-заказчиков (юридические лица и ИП), карточки с прокруткой, поиск по наименованию/ИНН/телефону, локальная проверка формата, предупреждения о дублях и несохранённых изменениях. Добавлена миграция № 4 (`counterparties`) без изменения прежних миграций; переход со схемы № 3 проверяется с сохранением слушателей и учебного центра, резервной копией и пробной миграцией существующим механизмом U01/S01. Новых зависимостей и сетевых функций нет. Локально прошли 182 теста, включая 36 новых проверок модели, репозитория, миграции и интерфейса. Проверки политики безопасности, Bandit и git diff --check прошли. [Windows CI для P02.3](https://github.com/AlekseyVinokurov/proficentr-desktop/actions/runs/44545788573) успешен: 182 теста, сборка onedir и helper, запуск EXE и сохранность карточки контрагента при обновлении.

Связи с договорами, обучением и оплатой, снимки реквизитов и договоры с физическими лицами остаются для P03. P02.4 не выполнялся.
