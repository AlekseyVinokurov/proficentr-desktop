# Состояние проекта

P01, P01.1, P02.1, P02.2 приняты; исходный коммит 6378427.

U01 + S01: реализованы проверка официальных релизов, Ed25519, внешний Windows updater, резервирование/пробные миграции, интерфейс «О программе», политика приватности, SECURITY.md и защищённый workflow выпуска. Основной сценарий собранного приложения проверяется Windows CI; локально Windows EXE не собирается. Локально и в Windows CI проходят 146 тестов (включая 98 исходных). [Windows CI с проверкой собранного приложения](https://github.com/AlekseyVinokurov/proficentr-desktop/actions/runs/44541542865) успешен: подпись тестового пакета, безопасная распаковка, отдельный helper, переключение onedir, подтверждённый запуск нового EXE, сохранность базы/вложения/настроек и отказ несовместимой схемы. U01/S01 реализован и проверен в этих пределах; проверка публичного канала между опубликованными релизами остаётся отдельным шагом после их выпуска.

До первого стабильного выпуска: утвердить лицензию и настройки защиты main/релизных тегов. Сам стабильный релиз не опубликован; публичный канал обновления между двумя официальными версиями ещё нельзя проверить. Authenticode, роли, шифрование базы и журнал аудита не реализованы. Порядок восстановления и технические ограничения — в updates.md.

P02.3 не выполнялся.
