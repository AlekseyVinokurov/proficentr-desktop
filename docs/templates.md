# DOCX-шаблоны

Откройте **Настройки → Шаблоны документов**. Нажмите **Добавить DOCX**, выберите файл, тип, вариант применения и название. Вариант различает формы одного типа, например `dpo`, `po` или `dpo-group`; используйте одинаковое обозначение при регистрации последующих версий. Тип и точный вариант образуют ключ выбора формы. Название служит для отображения.

Программа проверяет файл и формирует пробный результат в памяти. Ошибка не меняет прежние версии. По умолчанию новая версия становится активной; флажок позволяет зарегистрировать её без переключения. Для пары «тип + вариант» может быть активна только одна версия. В таблице видны все версии; выберите старую и нажмите **Активировать версию** для возврата.

Для изменения выберите версию и нажмите **Открыть копию в Word**. Откроется отдельный DOCX в установленном редакторе, оригинал реестра останется в `templates/`. Сохраните правки, затем нажмите **Новая версия** и загрузите изменённую копию. Тип и вариант при этом сохраняются. **Выгрузить копию…** сохраняет файл в выбранное место; существующие файлы программа не заменяет. Редактор Word не входит в приложение.

**Сформировать тестовый документ** создаёт новый файл `exports/template-tests/TEST-unregistered-<ID>.docx` и предлагает открыть его. Используются только вымышленные данные, независимо от содержания вашей базы. Это не зарегистрированный договор, приказ или согласие, у него нет юридического номера. Сформированные файлы не связаны с последующим редактированием шаблона. Изменять содержимое `templates/` вручную нельзя: проверка SHA-256 обнаружит повреждение, используйте выгрузку копии и регистрацию новой версии.

## Одиночные поля

В Word введите тег целиком, со всеми пробелами: `{{ center.full_name }}`. Его можно поместить в обычный текст, ячейку таблицы или колонтитул. Тег наследует оформление участка текста: шрифт, жирность, курсив. Не разбивайте один тег разным форматированием. Обычные изображения вставляйте непосредственно в Word; динамическая вставка файлов не поддерживается.

| Раздел | Доступные поля |
| --- | --- |
| `center` | `full_name`, `short_name`, `inn`, `kpp`, `ogrn`, `legal_address`, `actual_address`, `postal_address`, `phone`, `email`, `website`, `bank_name`, `bik`, `settlement_account`, `correspondent_account`, `director_name`, `director_position`, `director_genitive`, `license_number`, `license_date`, `license_authority` |
| `student` | `full_name`, `surname`, `first_name`, `patronymic`, `birth_date`, `snils`, `citizenship`, `phone`, `email`, `registration_address`, `residential_address`, `passport_series`, `passport_number`, `passport_issued_by`, `passport_issue_date`, `passport_department_code`, `education_level`, `education_document`, `education_details`, `workplace`, `job_title` |
| `customer` | `full_name`, `short_name`, `kind`, `inn`, `kpp`, `ogrn`, `legal_address`, `actual_address`, `postal_address`, `phone`, `email`, `bank_name`, `bik`, `settlement_account`, `correspondent_account`, `representative_name`, `representative_position`, `authority_basis` |
| `program` | `name`, `direction`, `kind`, `hours`, `code`, `edition`, `qualification`, `grade` |
| `training` | `start_date`, `end_date`, `state` |
| `document` | `number`, `date`, `is_test` |
| `group` | `name`, `start_date`, `end_date` |

Составное поле записывается через точку: `{{ program.hours }}`. Даты передаются готовыми строками; в тесте используется `ГГГГ-ММ-ДД`. Направление в тестовых данных — `dpo`, вид — `dpo_upskilling`. Число часов — число. Поле `document.is_test` — логическое значение. Отсутствующие обязательные значения вызывают ошибку генерации; необязательное поле следует передать пустой строкой. Полный список есть и в приложении по кнопке **Доступные поля**.

## Условия

Простое условие внутри абзаца:

```text
{% if customer.full_name %}Заказчик: {{ customer.full_name }}{% else %}Заказчик не указан{% endif %}
```

Для условного абзаца создайте три отдельных абзаца Word:

```text
{%p if document.is_test %}
Тестовый документ. Не зарегистрирован.
{%p endif %}
```

Служебные абзацы исчезнут из результата. Разрешены `if`, `elif`, `else`, `endif`, `not`, `and`, `or`, сравнения `==` и `!=` поля с постоянной строкой, числом или логическим значением. Например: `{% if program.direction == 'dpo' %}`. Другие выражения, фильтры и функции запрещены.

## Список слушателей

Создайте таблицу с заголовком и тремя строками ниже:

| Первая ячейка | Вторая ячейка |
| --- | --- |
| `{%tr for row in students %}` | Оставьте пустой |
| `{{ row.full_name }}` | `{{ row.start_date }}` |
| `{%tr endfor %}` | Оставьте пустой |

Средняя строка повторится для каждого слушателя, а две служебные строки исчезнут. Внутри цикла доступны все поля `student` и дополнительные `start_date`, `end_date` через переменную `row`. Можно добавить нужные столбцы. Условия внутри повторяемой строки допустимы. Вложенные циклы, фильтрация цикла и `loop.index` не поддерживаются. Список может содержать до 500 записей; пустой список удаляет повторяемую строку.

## Ограничения формата

Принимается обычный DOCX: до 10 МиБ в архиве, до 32 МиБ после распаковки, до 8 МиБ на часть и до 1000 частей. Чрезмерное сжатие и сложность XML/шаблона отклоняются. Данные ограничены 1 МиБ, строка — 10 000 знаков, вычисляемый объём результата — 16 МиБ XML; большие формы могут потребовать разделения.

Разрешены обычный текст, таблицы, колонтитулы, сноски и встроенные растровые изображения PNG/JPEG/GIF/BMP/TIFF. Макросы, OLE/ActiveX, вложенные документы, внешние гиперссылки и связанные изображения, поддокументы, динамические изображения, SVG/EMF/WMF, графики, нестандартные части пакета и DTD/сущности XML отклоняются. Из инструкций Word разрешены только `PAGE`, `NUMPAGES`, `SECTIONPAGES` (возможен `\* MERGEFORMAT`); другие автоматические поля, включая DDE, запрещены. Ссылки можно оставить обычным текстом без внешнего отношения Word. При отказе удалите неподдерживаемые элементы и сохраните обычный DOCX.

Шаблоны не получают доступа к файлам, функциям Python, моделям приложения или базе. Юридические тексты, их утверждение и применимость остаются ответственностью учебного центра. Этот этап предоставляет реестр форм и тестовую генерацию; реестр юридически значимых документов, нумерация, зачисление, подписи, PDF и ФРДО отсутствуют.
